│    5. Add Git: https://github.com/virahitvin8/crafty-gis.git │

│    7. Add env vars (from .env) → Deploy                      │

📋 BEFORE DEPLOYING — PREPARE THESE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Gather these from your .env file:

[ ] SENTINEL_HUB_CLIENT_ID (from Sentinel Hub dashboard)
[ ] SENTINEL_HUB_CLIENT_SECRET (from Sentinel Hub dashboard)
[ ] GEMINI_API_KEY (from https://aistudio.google.com/app/apikey)
[ ] GEE_SERVICE_ACCOUNT (from Google Cloud IAM)
[ ] GEE_PRIVATE_KEY (from Google Cloud service account JSON)

Optional:
[ ] OLLAMA_BASE_URL (if self-hosting Ollama)
[ ] OLLAMA_MODEL (default: deepseek-r1:7b)
[ ] OLLAMA_VISION_MODEL (default: llava-phi3)
