   cd /home/akshit/Desktop/claude_build/AGRI APP/server
   node server.js

2. OPEN IN BROWSER:
   http://localhost:3001

3. SIGN IN (100% FREE):
   • Click "Sign in with Google"
   • OR use Email/Password
   • OR use Mobile number (SMS)

4. SELECT YOUR FIELD:
   • Draw boundary directly on map
   • OR upload GeoJSON file
   • OR enter coordinates manually

5. RUN ANALYSIS:
   • Click "Analyze Field" button
   • System fetches satellite data (GEE/Sentinel Hub)
   • ML models compute stress classification
   • Charts render automatically

6. VIEW RESULTS:
   • Health score and stress level
   • Multi-spectral indices (NDVI, NDWI, EVI, NDMI)
   • ML predictions with confidence
   • Geospatial metadata (area, perimeter, CRS)
   • AI-generated recommendations

   • CSV — All parameters in spreadsheet
   • GeoJSON — Field boundary with properties
   • Excel — Multi-sheet report
